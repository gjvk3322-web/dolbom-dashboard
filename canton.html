캔톤페어 소싱 노트

카드를 누르면 중국어가 화면 가득 커진다. 업체 담당자에게 폰을 돌려 보여주고, 숫자는 계산기나 종이에 적어달라고 하면 된다. 제품 상세 화면의 「업체 질문·답변」에서 열면 답변까지 바로 기록된다.

140회 캔톤페어 (2026 가을) 일정

1기 10/15–19전자·가전·조명·기계·차량·공구·건자재 2기 10/23–27생활용품·주방·선물·홈데코·완구·개인용품·가구 — 콘텐츠형 생활 가젯의 핵심 구간 3기 10/31–11/4섬유·의류·신발·가방·사무·식품·헬스·육아·펫

개장 9:30–18:00, 광저우 파저우(琶洲) 전시장. 각 기 사이 3일 공백은 공장 방문·1688 검증·숙소 검토에 쓰기 좋다. 관별 세부 배치는 해마다 조금씩 바뀌니 공식 앱(Canton Fair)에서 출발 전 확인.

출발 전 준비

  • 바이어 사전등록 → 배지 발급 (현장 발급은 줄이 길다)
  • 위챗 설치 + 위챗페이/알리페이에 해외카드 연동. 부스 연락은 전부 위챗으로 이어진다
  • 명함 100장 이상, 보조배터리 2개, 편한 신발, 접이식 카트나 큰 가방(카탈로그가 금방 쌓임)
  • 파파고 이미지 번역, 계산기 앱을 첫 화면에
  • 이 페이지를 홈 화면에 추가 (Safari 공유 → 홈 화면에 추가). 설정 탭에서 환율 최신값 입력

하루 동선 — 관을 고르고 순서대로만

  • 전날 밤 공식 앱으로 볼 관(구역·층) 3~4개만 고른다. 관 하나가 크기 때문에 하루 2~3관이 현실적
  • A → B → C(→ D) 구역 순으로 이동을 최소화. 구역 간 이동만으로 20~30분 나간다
  • 점심은 12시 전에, 협상은 오후 4시 이후(부스가 한산해 담당자가 여유 있음)
  • 아래 체크리스트에 오늘 돌 관을 적어두고 끝낼 때마다 체크

부스 루틴 3분 — 생각은 숙소에서

  1. 사진 3장: 제품 / 부스 번호판 / 가격표·명함
  2. 질문 카드는 우선 3개만: 출고가 · MOQ · EXW/FOB
  3. 현장 2분 체크 저장 → 70점 미만이면 바로 다음 부스. 80점 이상만 나머지 질문까지 진행

망설이는 시간이 제일 큰 비용이다. 점수가 결정을 대신 하게 두고 몸은 계속 움직인다.

숙소 루틴 30분

  • 「숙소 검토 대기」 필터로 DEEP부터 10분 검토
  • TOP 후보·샘플만 결정한 업체에는 그날 밤 위챗으로 샘플·정식 견적 요청
  • 설정 → 백업 내보내기 1회 (사진이 폰 브라우저에만 있으니 매일)

처음 가는 사람이 빠지는 함정

  • 공장인지 무역회사인지 먼저 확인 — 你们是工厂还是贸易公司？ 무역회사는 가격이 한 단계 얹혀 있다
  • 부스가 크고 화려할수록 MOQ가 크다. 테스트 물량(300~500개)은 중소 부스가 맞는 경우가 많다
  • 가격은 단위(USD/RMB)와 조건(EXW/FOB, 항구)을 같이 적지 않으면 나중에 못 쓴다
  • 마음에 들면 그 자리에서 1688에 제품명 검색 — 내수 공장가와 차이가 크면 재협상 카드
  • 샘플·카탈로그는 들고 다니지 말고 호텔로 배송 요청. 배지 분실하면 재발급에 반나절 사라진다

표지(순위표) + 제품별 1페이지로 구성. 맥에서 같은 주소를 열고 설정 → 가져오기로 백업을 불러온 뒤 Cmd+P → PDF로 저장하면 제일 깔끔하다. 폰에서도 인쇄 버튼 → 미리보기를 손가락으로 벌리면 PDF로 저장된다.
